## 👋 About Me

I'm a high school student from Spain with a passion for programming, electronics, and technology in general.

I don't like limiting myself to a single language or framework. Instead, I enjoy exploring different areas of software development, experimenting with new ideas, and learning something new every time I start a project.

For me, programming isn't just about writing code—it's about solving problems, creating useful things, and having fun in the process.

Most of my projects start with a simple thought:

> **"What if I tried to build this?"**

Sometimes they work, sometimes they don't... but I always learn something valuable.
